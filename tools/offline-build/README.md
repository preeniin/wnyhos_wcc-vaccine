# เครื่องมือสร้าง CSS/ฟอนต์ที่ฝังใน index.html (ให้ใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต)

`index.html` ใช้คลาส Tailwind CSS และฟอนต์ Sarabun แต่ **ไม่โหลดจากอินเทอร์เน็ต** — CSS และฟอนต์ถูกสร้างล่วงหน้าแล้วฝังอยู่ในไฟล์เอง
(ระหว่างคอมเมนต์ `offline-assets:begin` ถึง `offline-assets:end` ใกล้ต้นไฟล์ **อย่าแก้ด้วยมือ**)

ทำไมฝังในไฟล์เดียว: สคริปต์ deploy ของ IT คัดลอกเข้าเว็บเฉพาะ `index.html`, `pcv-rules.js`, `admin.html`
ถ้าแยก CSS/ฟอนต์เป็นไฟล์ใหม่ หน้าเว็บจริงจะไม่มีสไตล์ (การตรวจของ deploy ตรวจแค่รหัสตอบกลับ จะไม่จับได้)

## กฎสำคัญ

**ทุกครั้งที่เพิ่ม/เปลี่ยนคลาส Tailwind ใน `index.html` (รวมในสตริง JS ที่สร้าง HTML) ต้องรัน build ใหม่** ไม่งั้นคลาสใหม่จะไม่มีสไตล์

```
cd tools/offline-build
npm install            # ครั้งแรกเท่านั้น (ต้องมีอินเทอร์เน็ต) — เฉพาะเครื่องคนแก้หน้าตา ไม่เกี่ยวกับ server
node build.js          # สร้างใหม่แล้วฝังลง index.html
node build.js --check  # ตรวจว่าที่ฝังไว้ยังตรง (exit 1 ถ้าล้าสมัย)
```

`node --test tests/offline.test.js` จะล้มถ้า CSS ที่ฝังล้าสมัย หรือมีการโหลดจากภายนอกโผล่กลับมา

## ข้อควรระวัง
- ชื่อคลาสที่ **ประกอบจากตัวแปรตอนรัน** (เช่น `'bg-' + color + '-100'`) ตัวสร้างมองไม่เห็น ต้องเขียนชื่อคลาสเต็มในโค้ด (ปัจจุบันไม่มีกรณีนี้)
- ฟอนต์: Sarabun น้ำหนัก 400/500/700/800 (ภาษาไทยและละติน) — Sarabun ไม่มี 900 `font-black` จึงใช้ 800
- รุ่นของเครื่องมือล็อกไว้ใน `package.json` (Tailwind 3.4.17, @fontsource/sarabun 5.1.0)
