#ช่วงอายุวัคซีนสัปดาห์ (พุธ)เวลาอายุถัดไป
กรอกวันที่เป็น พ.ศ. รูปแบบ วว/ดด/พ.ศ. (เช่น 10/12/2569) · ชื่อ "ยกเลิก" = ยกเลิกวันหยุดนั้น (เช่น วันหยุดที่ระบบคำนวณเองแต่คลินิกเปิดจริง) (ใส่แถว "ยกเลิก" วันที่เดียวกับวันหยุดนั้น วันที่ซ้ำกันได้ และ "ยกเลิก" ชนะเสมอ) · ชื่ออื่น = เพิ่มวันหยุด/ชดเชย · คลินิกให้บริการวันพุธ วันหยุดที่ตรงวันพุธเท่านั้นที่กระทบการนัด
วันที่ (พ.ศ.)วันชื่อผลต่อการนัด
ข้อความเหล่านี้แสดงบนหัวเว็บของเจ้าหน้าที่ (ชื่อระบบ, ชื่อ รพ.) และในหัวข้อบางจุด (ชื่อย่อคลินิก) · แก้เสร็จต้องกด บันทึก หน้าเว็บจะเปลี่ยนเมื่อรีเฟรช · ถ้าเปิดเว็บจากที่อื่นที่ไม่มี server นี้ (เช่น สำเนาบน GitHub Pages) จะใช้ข้อความตั้งต้นเดิม
