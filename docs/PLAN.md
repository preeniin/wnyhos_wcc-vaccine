# แผนงานและวิธีทำงานต่อ

อัปเดตล่าสุด: 3 พ.ย. 2569 กฎของระบบอยู่ใน [SYSTEM-RULES.md](SYSTEM-RULES.md)

## 1. สถานะตอนนี้

- เว็บจริงอยู่ที่ GitHub Pages ของ repo `preeniin/wnyhos_wcc-vaccine` สาขา `main` (เวอร์ชันล่าสุดที่ push คือ **48**; ในเครื่องผู้ดูแลมีงานที่แก้ต่อจากนั้นรอ commit ดูป้ายเวอร์ชันบนหัวเว็บ)
- **PCV ทำเสร็จและขึ้นเว็บจริงแล้ว** : ตรรกะ (`pcv-rules.js`), ช่องประวัติ, การ์ดผล, การ์ดแท็บแผนการฉีด, ตัวเลือก PCV เข็มเดี่ยวในแท็บผู้ปกครอง
- เทสต์: ตรรกะ 24 ข้อ + เทสต์หน้าเว็บ `tests/ui/` ผ่านทั้งหมด
- โปรเจกต์ "เซิร์ฟเวอร์ตั้งค่าเอง" (หน้า admin แก้ตารางวัคซีน/วันหยุดโดยไม่ผ่านชีต) **พับไว้ชั่วคราว** รอ IT (ดูข้อ 4)

## 2. วิธีทำงานต่อ (ทุกครั้งที่แก้โค้ด)

1. แก้ `index.html` / `pcv-rules.js`
2. ถ้าแก้กฎ PCV: แก้ `RULES` ใน `pcv-rules.js`, เทสต์ใน `tests/pcv.test.js`, ตารางในการ์ด PCV ของ `buildPcvPlanCard` (ซ้ำกับ `RULES` ต้องแก้ด้วยมือ) และ [SYSTEM-RULES.md](SYSTEM-RULES.md)
3. รันเทสต์
   ```
   node --test tests/pcv.test.js
   node tests/ui/run.js            # เพิ่ม --full ก่อนปล่อยของใหญ่, --mobile ดูความกว้างมือถือ
   ```
4. **เพิ่มเลขเวอร์ชัน** ที่ป้ายหัวเว็บ (`✨ เวอร์ชัน NN · วันที่ เวลา (คำอธิบาย)` ใน `index.html`) พร้อมวันเวลาปัจจุบันและคำอธิบายสั้น ๆ
5. commit แล้ว push ไป `main` เว็บจริงจะอัปเดตช้า (บางครั้งหลายนาที) ให้เปิดเว็บแล้วกด Ctrl+F5 ดูว่าเลขเวอร์ชันตรงกับที่ push
6. ถ้าแก้ข้อมูลที่ชีต: รอซิงก์อัตโนมัติ (ทุกชั่วโมง) หรือกด **Run workflow** ที่แท็บ Actions ของ GitHub (ไฟล์ `sync-sheets.yml`) ให้ไฟล์ `data/*.csv` อัปเดตทันที

ย้อนกลับถ้าเว็บจริงมีปัญหา: `git revert` ของ commit ที่ต้องการ (merge PCV = `fa364f1` ตามด้วยการแก้ภายหลัง) แล้ว push

## 3. งานที่เหลือ (เรียงตามความสำคัญ)

### ปรับปรุงเล็ก ๆ (ไม่เร่ง)
- ป้าย "53 wk" เล็ก ๆ ในการ์ดวันนัดและแท็บอื่น ยังเป็นสัปดาห์เต็ม อาจเปลี่ยนเป็น "สัปดาห์ + วัน" ให้เหมือนกล่องอายุ
- ตารางในการ์ด PCV แท็บแผนการฉีด สร้างจาก `RULES` อัตโนมัติ (ตอนนี้พิมพ์มือซ้ำ 2 ที่) พร้อมเทสต์เทียบกัน
- ให้ป้ายเวอร์ชันแสดงเวลาซิงก์ข้อมูลชีตล่าสุดด้วย (ตอนนี้เลขเวอร์ชันไม่เปลี่ยนเมื่อชีตซิงก์)
- ให้เลขเวอร์ชันเพิ่มอัตโนมัติ (เช่น GitHub Action ใส่รหัส commit) แทนการแก้มือ
- ถ้าอยากให้ผู้ปกครองเห็น PCV ในการ์ดรอบ 6 ด./9 ด./1 ปี 6 ด. ตรง ๆ แทนหมายเหตุ ต้องรู้ประวัติเด็ก (แท็บนั้นไม่มีช่องวันเกิด/ประวัติ) จึงเลือกใช้หมายเหตุไปก่อน
- มี PCV กรณีเด็กอายุ ≥ 24 เดือน: ตอนนี้แสดงข้อความ "พิจารณาตามชนิดวัคซีน" ไม่คำนวณ ถ้าต้องการรองรับต้องมีกฎจาก CPG ส่วนอื่น

### ที่ตัดสินใจแล้วว่า "ไม่ทำ"
- ปุ่ม "คัดลอกสรุปทั้งหมด" (HosXP แยกคนละช่อง วางรวมไม่ได้)
- ใบนัดพิมพ์ให้ผู้ปกครอง
- จำประวัติเด็กไว้ในเบราว์เซอร์ (ข้อมูลส่วนบุคคลของผู้ป่วย ไม่ควรเก็บในเครื่องที่หลายคนใช้)

## 4. โปรเจกต์เซิร์ฟเวอร์ (พับไว้ รอ IT)

**เป้าหมาย:** เว็บเดียวกันแต่ตารางวัคซีนและวันหยุดแก้ผ่านหน้า `/admin` (มีรหัสผ่านและบันทึกประวัติการแก้) ไม่ต้องผ่าน Google Sheets และเปิดสู่อินเทอร์เน็ตผ่าน Cloudflare Tunnel

**สถานะ:**
- โค้ดอยู่ที่สาขา `feature/admin-settings-server` (commit `3b51c0e`, **ยังไม่ได้ push**) โฟลเดอร์ `server/`: `server.js`, `lib.js`, `admin.html`, `set-password.js`, `ecosystem.config.cjs`, seed, เทสต์ 13 ข้อ (ไม่มี dependency ใช้ Node ล้วน)
- เคยติดตั้งทดลองบนเซิร์ฟเวอร์ภายในของโรงพยาบาลแล้ว (รันด้วย PM2) ตอนนี้ **หยุดอยู่** ข้อมูลที่ตั้งไว้ยังอยู่บนเครื่องนั้น รายละเอียดการเข้าถึง (ที่อยู่ เครื่อง บัญชี พอร์ต) **ไม่เขียนไว้ใน repo นี้ตั้งใจ** เพราะ repo เปิดสาธารณะ ให้ถามผู้ดูแลเดิมหรือดูบันทึกส่วนตัวของผู้ดูแล
- รหัสผ่านแอดมินตั้งโดยผู้ใช้เองด้วย `node set-password.js` ห้ามเขียนรหัสในแชทหรือโค้ด
- เซิร์ฟเวอร์เครื่องนั้นมีแอปอื่นของโรงพยาบาลและบริการของผู้ใช้อื่นอยู่ด้วย **ห้ามแตะ** ใช้เฉพาะโฟลเดอร์และโปรเซสของโปรเจกต์นี้

**ติดอะไรอยู่:**
- พอร์ตของบริการถูกไฟร์วอลล์บล็อกจากเครื่องผู้ใช้ ต้องให้ IT เปิด หรือใช้การทำอุโมงค์ SSH ชั่วคราวระหว่างทดสอบ
- Cloudflare Tunnel และ DNS ต้องให้ IT ทำ (ผู้ใช้ไม่ใช่ IT; ยังไม่ทราบโดเมนและผู้ติดต่อ)
- `crontab @reboot` สำหรับ `pm2 resurrect` ผู้ใช้ตั้งเองแล้ว อาจเปิดแอปขึ้นเองตอนรีบูต ถ้าไม่ต้องการ ใช้ `crontab -r`

**เมื่อ IT พร้อม ให้ย้าย PCV ไปฝั่งเซิร์ฟเวอร์:**
1. รวมสาขา `feature/admin-settings-server` เข้ากับ `main` ล่าสุด
2. **เพิ่มเส้นทางเสิร์ฟ `/pcv-rules.js`** ใน `server/server.js` — ตอนนี้เซิร์ฟเวอร์เสิร์ฟเฉพาะ `index.html` และ `/data/*.csv` (บรรทัด ~150) ถ้าไม่เพิ่ม หน้าเว็บจะหา `pcv-rules.js` ไม่เจอ และ PCV หายไปเงียบ ๆ (เทสต์ UI จะจับได้ที่หัวข้อ "ไม่พบ window.PCV")
3. คัดลอก `index.html` และ `pcv-rules.js` ล่าสุดไปไว้ที่ `WEB_DIR` ของเซิร์ฟเวอร์ แล้วรีสตาร์ท PM2
4. ถ้าให้แอดมินแก้ตารางวัคซีนผ่านหน้า admin: แถว 2 ด./4 ด./1 ปี ต้องมีรายการ `PCV/นิวโมค็อกคัส/injection` (ใช้ seed ใหม่จาก `data/vaccines.csv`)
5. หน้า admin ควรมีค่าตั้ง PCV เข็มเดี่ยว (วัน/สัปดาห์/ช่วงเวลา) แทน `PCV_WEEKS` ที่ฝังในโค้ด และตัวเลขระยะห่าง (`d3MinGapDays` ฯลฯ) ถ้าต้องการให้ปรับเองได้
6. ปิด GitHub Action ซิงก์ชีต เมื่อเลิกใช้ชีต (ตอนนี้ยังใช้อยู่ ไม่ต้องปิด)
7. รันเทสต์ UI กับเวอร์ชันบนเซิร์ฟเวอร์ (แก้ `ROOT`/URL ใน `tests/ui/run.js` ให้ชี้ที่เซิร์ฟเวอร์ถ้าต้องการ)

**สิ่งที่ต้องขอจาก IT:** เปิดพอร์ตของบริการภายใน LAN หรือให้ Cloudflare Tunnel ชี้มาที่บริการนี้บนเครื่องเซิร์ฟเวอร์ และขอโดเมนย่อย บริการเป็น Node ล้วน รันด้วย PM2 ภายใต้บัญชีผู้ใช้ของโปรเจกต์ ไม่มีผลต่อแอปอื่น (ใส่ที่อยู่/พอร์ตจริงตอนส่งข้อความ ไม่ใส่ใน repo)
