# กฎและการทำงานของระบบ (ระบบนัดหมายวัคซีน WCC)

เอกสารนี้อธิบาย "กฎ" ที่ระบบใช้คำนวณวันนัด โดยเฉพาะวัคซีน PCV ที่เพิ่มเมื่อ พ.ย. 2569 พร้อมเหตุผลและแหล่งอ้างอิง
สำหรับคนที่จะมาดูแลหรือแก้โค้ดต่อ ถ้าแก้กฎ ให้แก้เอกสารนี้และเทสต์ในคราวเดียวกัน

อ้างอิงเวลา: ใช้ปี พ.ศ. ในหน้าจอ และปี ค.ศ. ภายในโค้ด วันที่ในเอกสารนี้เขียนเป็น พ.ศ. เว้นแต่ระบุ

### การหาวันนัดรอบปกติ

`findNextApptDate(เริ่มหาจากวันที่, สัปดาห์ที่เปิด)` = วันพุธแรกที่ ≥ วันเริ่มหา ซึ่งสัปดาห์ของเดือนอยู่ในรายการที่เปิด และไม่ใช่วันหยุด (ค้นล่วงหน้าไม่เกิน 100 สัปดาห์ ไม่เจอ = ไม่แสดงวัน)

วันหยุดมาจาก 3 แหล่ง: วันหยุดคงที่ในโค้ด (`fixedHolidays`), วันพระ 4 วันต่อปี (`buddhistHolidayOffsets` ใส่ได้ถึงปี 2033) และชีตวันหยุด (วันที่ตรงกับ `ยกเลิก` = ยกเลิกวันหยุดนั้น)

**ปีที่ข้อมูลวันหยุดยังไม่ครบ** (เช่น พ.ศ. 2570 ที่ชีตยังไม่ลง) ระบบขึ้นป้ายเตือนสีเหลือง "ยังไม่ยืนยันวันหยุด" ใต้วันนัดที่ตกในปีนั้น

## 2. กฎ PCV

### 2.1 แหล่งอ้างอิง
- CPG "คำแนะนำการให้บริการวัคซีนนิวโมค็อกคัส" ตารางที่ 2 (คำแนะนำตามอายุที่เริ่มเข็มแรก รวมกรณีล่าช้า) และหมายเหตุใต้ตาราง (ไฟล์ PDF อยู่ในโฟลเดอร์โปรเจกต์ ไม่ได้ commit)
- ตารางข้อเสนอแนะ WHO ที่ผู้ใช้ส่งมา (กรณีลดระยะห่าง ≥ 4 สัปดาห์ และ booster หลังเข็มที่ 2 ≥ 8 สัปดาห์สำหรับผู้เริ่ม 7–11 เดือน)
- ตัวเลือกที่ CPG ให้หลายทาง ผู้ใช้เลือกหลัก **"ไปพร้อมวัคซีนอื่น มาน้อยครั้งที่สุด"** (ทางที่ไม่ได้ใช้เก็บไว้ในฟิลด์ `cpgAlt` ของ `RULES`)

### 2.4 วิธีหาวันของแต่ละเข็ม (`pcv-rules.js`)

อายุทุกที่นับเป็น "เดือนเต็ม" แบบเดียวกับกลุ่มอายุของแอป (`calculateDetailedAge`) การบวกเดือนใช้ `setMonth` เหมือนโค้ดเดิม

`notBefore` ของเข็มที่ n = วันที่เข็ม n−1 + ระยะห่างขั้นต่ำ

- **พร้อมรอบ X**: หาวันเปิดแรกของรอบ X นับจากวันที่ **ช้ากว่า** ระหว่าง (วันเกิด + อายุเป้าหมายของรอบ) กับ `notBefore` โดยใช้ `findNextApptDate` ด้วยสัปดาห์ของรอบ X ถ้าวันที่ได้เลยช่วงอายุของรอบ: ใช้รอบสำรอง (เฉพาะแถว 3) ไม่งั้นแสดงคำเตือน
- **เดี่ยว (อายุ N)**: วันพุธแรกที่ ≥ max(วันเกิด + N เดือน, `notBefore`) ในสัปดาห์ที่ PCV เปิด
- **เดี่ยว (ห่าง ≥ 8 สัปดาห์)**: วันพุธแรกที่ ≥ `notBefore`
- **PCV เดี่ยวเปิดทุกวันพุธ ช่วงเช้า** กำหนดไว้ที่ค่าเดียว `PCV_WEEKS = [1,2,3,4,5]` ใน `index.html` (ถ้าคลินิกเปลี่ยนเป็นเว้นสัปดาห์ ให้แก้ตรงนี้) เข็มเดี่ยวทุกเข็มมีค่า `session: 'เช้า'`
- **เข็มที่ไปพร้อมรอบ ใช้ช่วงเวลาของรอบนั้น** (รอบ 18 เดือนและ 4 ปีเป็นช่วงบ่ายก็ฉีด PCV ช่วงบ่ายพร้อมกัน) ไม่ต้องกำกับเช้า/บ่ายเพิ่ม
- เข็ม 1 "ทันที" = วันที่มารับบริการ (ไม่ผูกกับรอบ ไม่กำหนดช่วงเช้า)

### 2.5 ประวัติ PCV (อินพุตของ `PCV.plan`)

```js
PCV.plan({ birth, visit, history, env })
// history ว่าง/ไม่ใส่ = ยังไม่เคยฉีด
// { count: 1|2, startAge: <เดือนเต็มตอนฉีดเข็มแรก> }   ช่องบังคับเมื่อเคยฉีด
// + { dose1?: Date, dose2?: Date }                    ช่องเสริม ถ้ามีวันที่ ตรวจระยะห่างจากวันจริง
// { complete: true }                                    เจ้าหน้าที่ระบุว่าครบแล้ว → ไม่นัด
// env = { findDate, weeksFor, pcvWeeks }               ฟังก์ชัน/ข้อมูลจาก index.html
```

เหตุผลที่ไม่บังคับวันที่ฉีด: แอปไม่มีฐานข้อมูล ไม่รู้ว่าเด็กฉีดอะไรไปวันไหน ผู้ปกครองมักจำวันที่ไม่ได้ จึงใช้ "จำนวนเข็ม + อายุตอนฉีดเข็มแรก" เป็นหลัก

ผลลัพธ์: `{ ok, complete, unverifiedGap, startMonths, doses[], cpgAlt }` หรือ `{ ok:false, code, message }` (`too-young`, `too-old`, `bad-input`, `bad-history`)

แต่ละ dose: `{ n, state, date, withVisit, label, session, warnings[], notes[] }`
- `state`: `given` (ฉีดแล้ว), `today` (เข็ม 1 วันนี้), `due` (ถึงกำหนดแล้ว ฉีดวันนี้), `planned` (นัด), `unavailable` (หาวันไม่ได้)
- `due`: เด็กมีประวัติและเข็มถัดไปเลยกำหนดแล้ว และห่างเข็มก่อนพอ → ฉีดวันที่มารับบริการ (ไม่ติดป้ายรอบ ไม่กำหนดช่วงเช้า)
- ถ้าไม่ทราบวันที่ฉีดเข็มก่อนหน้า: ไม่บังคับระยะห่าง และขึ้นหมายเหตุ "ไม่ได้ตรวจระยะห่างจากเข็มก่อน (ไม่ได้ระบุวันที่ฉีด)" (`unverifiedGap: true`)

ตัวเลือกประวัติในหน้าจอ: ยังไม่เลือก (ไม่มีค่าเริ่มต้น) / ยังไม่เคยฉีด / ฉีดแล้ว 1 เข็ม / ฉีดแล้ว 2 เข็ม / ครบแล้ว / ไม่ทราบ-ไม่มีสมุด
- **ยังไม่เลือก** = ขึ้น "กรุณาระบุประวัติ PCV ก่อน" ไม่เดาแผน (ยกเว้นอายุ ≥ 24 เดือนที่แสดงข้อความของระบบ)
- **ไม่ทราบ** = ขึ้นข้อความให้ตรวจสมุด/HosXP ก่อน ไม่แสดงวันนัด
- **ครบแล้ว** = เชื่อตามที่เจ้าหน้าที่เลือก ไม่ตรวจวันที่ย้อนหลัง

## 3. พฤติกรรมของหน้าจอ

### 3.1 แท็บ "นัดหมายตามอายุ" (สำหรับเจ้าหน้าที่)

อินพุต: วันเกิด, วันที่มารับบริการ (ค่าเริ่มต้นวันนี้), ประวัติ PCV กด Enter ในช่องวันที่ = กด "คำนวณวันนัด" จอกว้างเคอร์เซอร์อยู่ที่ช่องวันเกิดเอง มือถือไม่ทำ

ทันทีที่กรอกวันที่ (ไม่ต้องกดคำนวณ) แสดงกล่อง "อายุ ณ วันที่มารับบริการ" (ปี เดือน วัน และ เดือนรวม + สัปดาห์ + วัน) และปิดตัวเลือก "อายุตอนฉีดเข็มแรก" ที่มากกว่าอายุปัจจุบัน

หน้าผลลัพธ์ (modal) ประกอบด้วย
1. **อายุ** (ปี เดือน วัน / สัปดาห์ วัน)
2. **การ์ดม่วง "วันนัดครั้งถัดไป"** วันนัดรอบปกติถัดไป พร้อมรายการวัคซีนของรอบนั้น (ชิปเล็กสีเทา เบากว่าการ์ดวันนี้ เพื่อไม่ให้สับสน)
3. **การ์ดเขียว "ต้องฉีดวันนี้"** วัคซีนของรอบปัจจุบัน
4. **การ์ดฟ้า "PCV: เข็มที่เหลือ"** เฉพาะเข็มที่ไม่อยู่ในสองการ์ดบน ซ่อนทั้งการ์ดถ้าไม่เหลือ ไม่มีปุ่ม Copy (กัน Copy ผิดวัน)
5. ปฏิทินเดือนของวันนัด

กติกาการจัดเข็ม PCV เข้าการ์ด (`pcvMergedBody` ใน `index.html`)
- เข็ม `today`/`due` → แถวสีฟ้าเส้นประต่อท้ายรายการวัคซีนในการ์ดเขียว
- เข็มที่ไปพร้อมรอบ (หรือเข็มเดี่ยวที่บังเอิญตกวันเดียวกัน) และตรงกับวันนัดปกติถัดไป → เป็นชิป `PCVn` ในรายการของการ์ดม่วง + ข้อความเล็ก "ไปพร้อมรอบนี้ ไม่ต้องนัดเพิ่ม" + การ์ดตัวเลขระยะห่าง
- ถ้ามี **PCV เข็มเดี่ยวที่ต้องมาก่อนนัดปกติถัดไป** → การ์ด "วันนัดครั้งถัดไป" **เป็นเข็มเดี่ยวนั้น** (ผู้ปกครองจะไม่ข้ามนัด) แสดงนัดเดียว ไม่มี "นัดต่อจากนั้น" เพราะทำให้ Copy ผิดวัน เข็มที่เหลือไปอยู่การ์ดฟ้า
- ถ้ามีประวัติแล้ว แถว "PCV" ทั่วไปที่ชีตใส่ไว้ในการ์ดเขียวและรายการวัคซีนรอบหน้าจะถูกถอด แล้วใช้แถวตามแผนรายคนแทน (กันซ้ำ และกันบอกให้ฉีดทั้งที่ครบ/ไม่ถึงกำหนด) ถ้ายังไม่เลือกประวัติ แถว PCV ทั่วไปจากชีตยังแสดง

**การ์ดระยะห่าง:** ใต้แต่ละเข็มที่มีวันที่ของเข็มก่อนหน้า แสดง "ห่างจากเข็ม n−1 = X สัปดาห์" เป็นการ์ดตัวเลขแยก (ข้อความหมายเหตุสีเหลืองไม่ซ้ำตัวเลข)

### 3.2 แท็บ "ค้นหาวันฉีด / ล่าช้า" (สำหรับผู้ปกครอง)

เลือกรอบอายุ แล้วแสดงวัคซีนของรอบและวันเปิดให้บริการถัดไป
- ตัวเลือกพิเศษท้ายรายการ **"PCV เข็มเดี่ยว · ทุกวันพุธ ช่วงเช้า"** → ข้อมูล PCV + วันพุธถัดไปที่เปิด
- การ์ดรอบ 6 ด./9 ด./1 ปี/1 ปี 6 ด. มีหมายเหตุ "เด็กที่เริ่ม PCV ช้า อาจรับ PCV พร้อมรอบนี้ หรือเลือก 'PCV เข็มเดี่ยว'…" (ข้อความแบบทั่วไป เพราะแท็บนี้ไม่รู้ประวัติเด็ก)
- รอบ 2 ด./4 ด./1 ปี แสดง `PCV` (ไม่มีเลขเข็ม) ตามชีต

### 3.3 แท็บ "แผนการฉีดวัคซีน"

การ์ดทุกรอบจากชีต + การ์ด PCV ท้ายตาราง (รอบปกติ, เข็มเดี่ยว ทุกวันพุธ ช่วงเช้า, ระยะห่าง, ตารางตามอายุที่เริ่มเข็มแรกแบบพับเก็บ) ตารางในการ์ดนี้ **พิมพ์ไว้ในโค้ด** (`buildPcvPlanCard`) ไม่ได้สร้างจาก `RULES` ถ้าแก้กฎต้องแก้ตารางนี้ด้วย

### 3.4 เลขเวอร์ชัน

ป้ายบนหัวเว็บ "✨ เวอร์ชัน NN · วันที่ เวลา (คำอธิบาย)" ต้องเพิ่มเลขทุกครั้งที่ commit+push แก้ `index.html` เพราะ GitHub Pages อัปเดตช้า ใช้เปรียบเทียบว่าเว็บจริงเป็นเวอร์ชันที่เพิ่ง push หรือยัง (กด Ctrl+F5) การซิงก์ชีตอัตโนมัติไม่เปลี่ยนเลขนี้

## 5. ข้อสมมุติและจุดที่ยังไม่แน่ใจ

- ระยะห่าง booster 8 สัปดาห์สำหรับผู้เริ่ม 2–6 เดือน ไม่มีแหล่งอ้างอิงตรง (ผู้ใช้ตัดสินใจใช้) ถ้าพบแหล่งที่ต่างออกไป แก้ `d3MinGapDays` ใน `RULES`
- เข็มที่ "พร้อมรอบ" ระบบหาวันเปิดของรอบนั้นเอง ถ้าเด็กมาไม่ตรงวันเปิดของรอบที่ผูก ระบบแสดงตามวันที่ที่มา (เหมือนวัคซีนอื่น) ไม่เตือนเพิ่ม
- วันนัดที่ตกปีที่ข้อมูลวันหยุดยังไม่ครบ ใช้ได้เฉพาะเมื่อคนอ่านป้ายเตือน (พ.ศ. 2570 ณ ปัจจุบัน)
- ตัวเลข "ห่างจากเข็มก่อน" ในหน้าจอคำนวณจากวันที่ของเข็มก่อนหน้าเท่านั้น ถ้าเข็มก่อนหน้าไม่ทราบวันที่จะไม่แสดง
- ตารางสรุปในการ์ด PCV แท็บแผนการฉีด (3.3) ซ้ำกับ `RULES` ต้องแก้สองที่
- ยังไม่ได้ตรวจบนมือถือเครื่องจริง

## 6. การทดสอบ

| คำสั่ง | ตรวจอะไร |
|---|---|
| `node --test tests/pcv.test.js` | ตรรกะ PCV: ตัวอย่างที่ตกลงกัน, ทุกแถว 2–23 เดือน (วันพุธ ไม่ใช่วันหยุด ลำดับ ระยะห่างตามกฎ), ประวัติ, เพดาน, ขอบอายุ, ข้อมูลผิดปกติ |
| `node tests/ui/run.js` | หน้าเว็บจริง ~3,000 กรณี (อายุ × วันที่มา × ประวัติ): ไม่มี error/ข้อความผิดปกติ, เข็ม PCV ทุกเข็มปรากฏครบ, วันนัดครั้งถัดไปไม่ช้ากว่าเข็มเดี่ยว, เข็มที่ตกวันเดียวกันรวมเป็นนัดเดียว, ไม่มีปุ่มในการ์ด PCV, แท็บค้นหา, อายุสด, Enter, รีเซ็ต, แท็บแผน |
| `node tests/ui/run.js --full` | เหมือนกันแต่ละเอียดกว่า (~10,000 กรณี ใช้เวลาหลายนาที) |
| `node tests/ui/run.js --mobile` | เหมือนกันที่ความกว้างมือถือ (390 พิกเซล) |

เทสต์ UI ต้องมี Google Chrome หรือ Microsoft Edge (ตั้ง `CHROME_PATH` ถ้าอยู่ที่อื่น) และไม่ต้องติดตั้งแพ็กเกจ รันก่อน commit ทุกครั้งที่แก้ `index.html` หรือ `pcv-rules.js`
