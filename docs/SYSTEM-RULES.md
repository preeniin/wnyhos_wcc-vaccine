# กฎและการทำงานของระบบ (ระบบนัดหมายวัคซีน WCC)

เอกสารนี้อธิบาย "กฎ" ที่ระบบใช้คำนวณวันนัด โดยเฉพาะวัคซีน PCV ที่เพิ่มเมื่อ พ.ย. 2569 พร้อมเหตุผลและแหล่งอ้างอิง
สำหรับคนที่จะมาดูแลหรือแก้โค้ดต่อ ถ้าแก้กฎ ให้แก้เอกสารนี้และเทสต์ในคราวเดียวกัน

อ้างอิงเวลา: ใช้ปี พ.ศ. ในหน้าจอ และปี ค.ศ. ภายในโค้ด วันที่ในเอกสารนี้เขียนเป็น พ.ศ. เว้นแต่ระบุ

### การหาวันนัดรอบปกติ

`findNextApptDate(เริ่มหาจากวันที่, สัปดาห์ที่เปิด)` = วันพุธแรกที่ ≥ วันเริ่มหา ซึ่งสัปดาห์ของเดือนอยู่ในรายการที่เปิด และไม่ใช่วันหยุด (ค้นล่วงหน้าไม่เกิน 100 สัปดาห์ ไม่เจอ = ไม่แสดงวัน)

วันหยุดมาจาก 3 แหล่ง: วันหยุดคงที่ในโค้ด (`fixedHolidays`), วันพระ 4 วันต่อปี (`buddhistHolidayOffsets` ใส่ได้ถึงปี 2033) และชีตวันหยุด (วันที่ตรงกับ `ยกเลิก` = ยกเลิกวันหยุดนั้น)

**ปีที่ข้อมูลวันหยุดยังไม่ครบ** (เช่น พ.ศ. 2570 ที่ชีตยังไม่ลง) ระบบขึ้นป้ายเตือนสีเหลือง "ยังไม่ยืนยันวันหยุด" ใต้วันนัดที่ตกในปีนั้น

## 2. กฎ PCV

### 2.1 แหล่งอ้างอิง
- CPG "คำแนะนำการให้บริการวัคซีนนิวโมค็อกคัส" ตารางที่ 2 (คำแนะนำตามอายุที่เริ่มเข็มแรก รวมกรณีล่าช้า) และหมายเหตุใต้ตาราง (ไฟล์ PDF อยู่ในโฟลเดอร์โปรเจกต์ ไม่ได้ commit)
- ตารางข้อเสนอแนะ WHO ที่ผู้ใช้ส่งมา (กรณีลดระยะห่าง ≥ 4 สัปดาห์ และ booster หลังเข็มที่ 2 ≥ 8 สัปดาห์สำหรับผู้เริ่ม 7–11 เดือน)
- ตัวเลือกที่ CPG ให้หลายทาง ผู้ใช้เลือกหลัก **"ไปพร้อมวัคซีนอื่น มาน้อยครั้งที่สุด"** (ทางที่ไม่ได้ใช้เก็บไว้ในฟิลด์ `cpgAlt` ของ `RULES`)

### 2.4 วิธีหาวันของแต่ละเข็ม (`pcv-rules.js`)

อายุทุกที่นับเป็น "เดือนเต็ม" แบบเดียวกับกลุ่มอายุของแอป (`calculateDetailedAge`) การบวกเดือนใช้ `setMonth` เหมือนโค้ดเดิม

`notBefore` ของเข็มที่ n = วันที่เข็ม n−1 + ระยะห่างขั้นต่ำ

- **พร้อมรอบ X**: หาวันเปิดแรกของรอบ X นับจากวันที่ **ช้ากว่า** ระหว่าง (วันเกิด + อายุเป้าหมายของรอบ) กับ `notBefore` โดยใช้ `findNextApptDate` ด้วยสัปดาห์ของรอบ X ถ้าวันที่ได้เลยช่วงอายุของรอบ: ใช้รอบสำรอง (เฉพาะแถว 3) ไม่งั้นแสดงคำเตือน
- **ข้อยกเว้นของ "พร้อมรอบ X": ถ้ามีประวัติแล้ว และวันที่มารับบริการอยู่ในช่วงอายุของรอบ X อยู่แล้ว** (ตามตารางในข้อ 1: เช่น รอบ 1 ปี = อายุ 12–<18 เดือน) ให้ถือว่าเข็มนั้น **ถึงกำหนดวันนี้ (state `due`) ฉีดพร้อมวัคซีนของรอบ** ไม่ต้องรอวันเปิดถัดไป เพราะการ์ด "ต้องฉีดวันนี้" ของแอปแสดงวัคซีนของช่วงอายุปัจจุบันโดยไม่ดูว่าวันนี้เป็นสัปดาห์ที่เปิดหรือไม่ ถ้า PCV ที่ผูกกับรอบเดียวกันถูกเลื่อนไปวันอื่น จะขัดกัน (เจอจริงเมื่อ 3 พ.ย. 2569: เด็ก 12 เดือน ฉีดแล้ว 2 เข็ม มาวันอังคาร) เงื่อนไข: ห่างเข็มก่อนพอแล้วเท่านั้น (ถ้ามีวันที่ฉีดจริงและห่างไม่ถึง 8 สัปดาห์ จะยังเป็น "นัด")
- **คำเตือน "ล่าช้ามาก"** (ผู้ใช้สั่งให้เตือน 3 พ.ย. 2569): เข็มที่ "ถึงกำหนดวันนี้" ถ้าอายุวันนี้ช้ากว่าอายุที่ตารางกำหนดไว้ ≥ `LATE_WARN_MONTHS` (ตั้งไว้ 6 เดือน ค่าเดียวใน `pcv-rules.js` — ผู้ตรวจยืนยันตัวเลข 6 เดือนแล้วเมื่อ 3 พ.ย. 2569 ปรับได้) จะมีคำเตือนสีแดง "ล่าช้ากว่ากำหนดประมาณ N เดือน (ตามตารางควรได้เมื่ออายุ X เดือน) — ให้แพทย์พิจารณาก่อนฉีด" อายุที่ตารางกำหนด: เข็มพร้อมรอบ = อายุของรอบ, เข็มเดี่ยวตามอายุ = N เดือน, เข็มเดี่ยวห่าง 8 สัปดาห์ = อายุตอนเริ่ม + 2 เดือน
- **เดี่ยว (อายุ N)**: วันพุธแรกที่ ≥ max(วันเกิด + N เดือน, `notBefore`) ในสัปดาห์ที่ PCV เปิด
- **เดี่ยว (ห่าง ≥ 8 สัปดาห์)**: วันพุธแรกที่ ≥ `notBefore`
- **PCV เดี่ยวเปิดทุกวันพุธ ช่วงเช้า** กำหนดไว้ที่ค่าเดียว `PCV_WEEKS = [1,2,3,4,5]` ใน `index.html` (ถ้าคลินิกเปลี่ยนเป็นเว้นสัปดาห์ ให้แก้ตรงนี้) เข็มเดี่ยวทุกเข็มมีค่า `session: 'เช้า'`
- **เข็มที่ไปพร้อมรอบ ใช้ช่วงเวลาของรอบนั้น** (รอบ 18 เดือนและ 4 ปีเป็นช่วงบ่ายก็ฉีด PCV ช่วงบ่ายพร้อมกัน) ไม่ต้องกำกับเช้า/บ่ายเพิ่ม
- เข็ม 1 "ทันที" = วันที่มารับบริการ (ไม่ผูกกับรอบ ไม่กำหนดช่วงเช้า)

### 2.5 ประวัติ PCV (อินพุตของ `PCV.plan`)

```js
PCV.plan({ birth, visit, history, highRisk, env })
// highRisk: true = เด็กกลุ่มเสี่ยงสูง (ดู 2.6)
// history ว่าง/ไม่ใส่ = ยังไม่เคยฉีด
// { count: 1|2, startAge: <เดือนเต็มตอนฉีดเข็มแรก> }   ช่องบังคับเมื่อเคยฉีด
// + { dose1?: Date, dose2?: Date }                    ช่องเสริม ถ้ามีวันที่ ตรวจระยะห่างจากวันจริง
// { complete: true }                                    เจ้าหน้าที่ระบุว่าครบแล้ว → ไม่นัด
// env = { findDate, weeksFor, pcvWeeks, product? }     ฟังก์ชัน/ข้อมูลจาก index.html · product = { name, maxAgeMonths, advice } (ดู 2.7)
```

เหตุผลที่ไม่บังคับวันที่ฉีด: แอปไม่มีฐานข้อมูล ไม่รู้ว่าเด็กฉีดอะไรไปวันไหน ผู้ปกครองมักจำวันที่ไม่ได้ จึงใช้ "จำนวนเข็ม + อายุตอนฉีดเข็มแรก" เป็นหลัก

ผลลัพธ์: `{ ok, complete, unverifiedGap, startMonths, doses[], cpgAlt, highRisk }` (`highRisk` = `null` ถ้าไม่ติ๊ก หรือ `{ schedule:'3p+1', mode:'standard'|'specialist'|'complete', message }`) หรือ `{ ok:false, code, message }` (`too-young`, `too-old`, `bad-input`, `bad-history`)

แต่ละ dose: `{ n, state, date, withVisit, label, session, warnings[], notes[], productBlocked? }`
- `state`: `given` (ฉีดแล้ว), `today` (เข็ม 1 วันนี้), `due` (ถึงกำหนดแล้ว ฉีดวันนี้), `planned` (นัด), `unavailable` (หาวันไม่ได้)
- `due`: เด็กมีประวัติและเข็มถัดไปเลยกำหนดแล้ว และห่างเข็มก่อนพอ → ฉีดวันที่มารับบริการ (ไม่ติดป้ายรอบ ไม่กำหนดช่วงเช้า)
- ถ้าไม่ทราบวันที่ฉีดเข็มก่อนหน้า: ไม่บังคับระยะห่าง และขึ้นหมายเหตุ "ไม่ได้ตรวจระยะห่างจากเข็มก่อน (ไม่ได้ระบุวันที่ฉีด)" (`unverifiedGap: true`)

ตัวเลือกประวัติในหน้าจอ: ยังไม่เลือก (ไม่มีค่าเริ่มต้น) / ยังไม่เคยฉีด / ฉีดแล้ว 1 เข็ม / ฉีดแล้ว 2 เข็ม / ครบแล้ว / ไม่ทราบ-ไม่มีสมุด
- **ยังไม่เลือก** = ขึ้น "กรุณาระบุประวัติ PCV ก่อน" ไม่เดาแผน (ยกเว้นอายุ ≥ 24 เดือนที่แสดงข้อความของระบบ)
- **ไม่ทราบ** = ขึ้นข้อความให้ตรวจสมุด/HosXP ก่อน ไม่แสดงวันนัด
- **ครบแล้ว** = เชื่อตามที่เจ้าหน้าที่เลือก ไม่ตรวจวันที่ย้อนหลัง

### 2.6 เด็กกลุ่มเสี่ยงสูง (สูตร 3p+1) — เพิ่ม 14 พ.ย. 2569

ผู้ใช้สั่งเพิ่มช่องติ๊ก "เด็กกลุ่มเสี่ยงสูง" (ภูมิคุ้มกันบกพร่อง ไม่มีม้าม โรคเรื้อรัง เช่น โรคปอด โรคหัวใจ) ที่มา: CPG หน้า 8 ข้อ 6 — สูตร 3p+1 = ชุดเบื้องต้น 3 เข็มที่อายุ 2, 4, 6 เดือน + เข็มกระตุ้น 1 เข็มที่ 12–15 เดือน และให้ปรึกษากุมารแพทย์เป็นรายบุคคล (อาจต้องใช้วัคซีนนิวโมค็อกคัสชนิดอื่นเพิ่ม)

**CPG ไม่มีตารางล่าช้าของสูตรนี้ ระบบจึงไม่คิดเลขเองเกินที่ CPG ระบุ:**

| เด็กที่ติ๊กกลุ่มเสี่ยงสูง | ระบบทำอะไร (`highRisk.mode`) |
|---|---|
| เริ่มเข็มแรกตอน **2–3 เดือน** (รวมมีประวัติ 1–2 เข็มที่เริ่มตอน 2–3 เดือน) | `standard`: คำนวณครบ 4 เข็ม เข็ม 1 ตามเดิม, เข็ม 2 พร้อมรอบ 4 ด., เข็ม 3 พร้อมรอบ 6 ด., เข็ม 4 (กระตุ้น) พร้อมรอบ 1 ปี มีแถบเหลืองอธิบายสูตร |
| เริ่มหลัง 3 เดือน | `specialist`: แสดง **แผนสูตรปกติ (2p+1)** พร้อมแถบแดง "แผนอาจไม่พอ ต้องให้กุมารแพทย์กำหนด" และ **ไม่ขึ้นว่า "ครบ" เด็ดขาด** (แม้แผนปกติจะครบแล้ว) |
| เจ้าหน้าที่เลือก "ครบแล้ว" | `complete`: ไม่นัด แต่มีข้อความเตือนให้ตรวจว่าครบตามสูตรที่กุมารแพทย์กำหนด |

ระยะห่างขั้นต่ำของโหมด `standard` ที่ผู้พัฒนาตั้งเอง (**ไม่มีใน CPG** ขอให้ผู้เชี่ยวชาญยืนยัน): ชุดเบื้องต้น ≥ 28 วัน (CPG: แนะนำ 8 สัปดาห์ ลดได้ถึง 4), กระตุ้นห่างเข็ม 3 ≥ 56 วัน เตือนถ้าเข็มกระตุ้นเลย 15 เดือน เข็ม 2–3 ที่เด็กมาช้าถูกเลื่อนตามระยะห่าง (ไม่ซ้อนวันเดียวกัน) ตัวตรวจ: `tests/pcv-highrisk.test.js` (รวมกวาดเงื่อนไขที่ต้องเป็นจริงเสมอ), กรณี R01–R06 ใน `tests/golden/`

หน้าจอ: ช่องติ๊กอยู่ใต้ช่อง "ประวัติ PCV" ล้างค่าเมื่อกดรีเซ็ต แถบเตือนอยู่บนสุดของการ์ด PCV เสมอ (ไม่ซ่อนแม้ไม่มีเข็มเหลือ)

### 2.7 วัคซีนของแผนงานและอายุสูงสุดที่รับรอง — เพิ่ม 14 พ.ย. 2569

วัคซีนของแผนงานตอนนี้คือ **SII PNEUMOSIL (PCV10)** ทะเบียนรับรอง 6 สัปดาห์ถึง **ก่อนครบ 2 ปี** (แนวทางปีงบ 2570 หน้า 6–7: เด็กเริ่ม 1 ปี 11 เดือน เข็ม 2 "ไม่ควรให้ SII PNEUMOSIL") ผู้ใช้ยืนยัน:
- เข็มที่ตกตอนอายุ ≥ `maxAgeMonths` (ตอนนี้ 24 เดือน นับเป็นเดือนเต็ม: 23 เดือน 29 วันยังใช้ได้) → `productBlocked: true` + คำเตือน "ให้เข็มนี้ด้วยวัคซีนนี้ไม่ได้ — แนะนำผู้ปกครองไปฉีดเข็มนี้ที่อื่นด้วย PCV ชนิดอื่น (คลินิกไม่มี PCV ชนิดอื่น และไม่มีการส่งต่อ) · เด็กยังต้องได้ครบจำนวนเข็ม"
- **ยังแสดงวันที่เร็วที่สุดที่ทำได้** เพราะเด็กยังต้องได้ครบจำนวนเข็ม ไม่ลบเข็มทิ้ง
- ใช้กับทุกเข็มที่ตกอายุนั้น รวมเข็ม 2 ของเด็กเริ่ม 19–23 เดือน (ยกเลิกข้อยกเว้นเดิม) และ **แทนที่** ข้อความทั่วไป "ตกตอนอายุ ≥ 24 เดือน — ปรึกษาแพทย์" ในเข็มเดียวกัน (ไม่ซ้อนกัน) คำเตือนอื่น เช่น ล่าช้ามาก ยังอยู่
- **ตั้งค่าที่เดียว:** `PCV_PRODUCT = { name, maxAgeMonths, advice }` ใน `index.html` ส่งเข้า `env.product` (ไม่ระบุ = ค่าตั้งต้นใน `DEFAULT_PRODUCT` ของ `pcv-rules.js`) ถ้าแผนงานเปลี่ยนวัคซีนหรือคลินิกมี PCV ชนิดอื่น แก้ที่นี่ ไม่ต้องแก้กฎ (เล่มระบุอายุรับรองของยี่ห้ออื่น: Synflorix ถึง 5 ปี, Weuphoria ถึง 6 ปี, PCV13/15/20 ไม่จำกัด)
- เด็กที่ **เริ่มเข็มแรก** ตอน ≥ 24 เดือน (ไม่มีประวัติ): ไม่คำนวณแผน (ไม่ฉีดตามแผนงาน) ตามเดิม · การเริ่มย้อนหลังทำได้ถ้ายังไม่ถึง 24 เดือน ไม่จำกัดวันเกิด รวมเด็กต่างชาติ (ผู้ดูแลแจ้ง 14 พ.ย. 2569)

## 3. พฤติกรรมของหน้าจอ

### 3.1 แท็บ "นัดหมายตามอายุ" (สำหรับเจ้าหน้าที่)

อินพุต: วันเกิด, วันที่มารับบริการ (ค่าเริ่มต้นวันนี้), ประวัติ PCV, ช่องติ๊ก "เด็กกลุ่มเสี่ยงสูง" (2.6) กด Enter ในช่องวันที่ = กด "คำนวณวันนัด" จอกว้างเคอร์เซอร์อยู่ที่ช่องวันเกิดเอง มือถือไม่ทำ

ทันทีที่กรอกวันที่ (ไม่ต้องกดคำนวณ) แสดงกล่อง "อายุ ณ วันที่มารับบริการ" (ปี เดือน วัน และ เดือนรวม + สัปดาห์ + วัน) และปิดตัวเลือก "อายุตอนฉีดเข็มแรก" ที่มากกว่าอายุปัจจุบัน

หน้าผลลัพธ์ (modal) ประกอบด้วย
1. **อายุ** (ปี เดือน วัน / สัปดาห์ วัน)
2. **การ์ดม่วง "วันนัดครั้งถัดไป"** วันนัดรอบปกติถัดไป พร้อมรายการวัคซีนของรอบนั้น (ชิปเล็กสีเทา เบากว่าการ์ดวันนี้ เพื่อไม่ให้สับสน)
3. **การ์ดเขียว "ต้องฉีดวันนี้"** วัคซีนของรอบปัจจุบัน
4. **การ์ดฟ้า "PCV: เข็มที่เหลือ"** เฉพาะเข็มที่ไม่อยู่ในสองการ์ดบน ซ่อนทั้งการ์ดถ้าไม่เหลือ ไม่มีปุ่ม Copy (กัน Copy ผิดวัน)
5. ปฏิทินเดือนของวันนัด

กติกาการจัดเข็ม PCV เข้าการ์ด (`pcvMergedBody` ใน `index.html`)
- เข็ม `today`/`due` → แถวสีฟ้าเส้นประต่อท้ายรายการวัคซีนในการ์ดเขียว
- เข็มที่ไปพร้อมรอบ (หรือเข็มเดี่ยวที่บังเอิญตกวันเดียวกัน) และตรงกับวันนัดปกติถัดไป → เป็นชิป `PCVn` ในรายการของการ์ดม่วง + ข้อความเล็ก "ไปพร้อมรอบนี้ ไม่ต้องนัดเพิ่ม" + การ์ดตัวเลขระยะห่าง
- ถ้ามี **PCV เข็มเดี่ยวที่ต้องมาก่อนนัดปกติถัดไป** → การ์ด "วันนัดครั้งถัดไป" **เป็นเข็มเดี่ยวนั้น** (ผู้ปกครองจะไม่ข้ามนัด) แสดงนัดเดียว ไม่มี "นัดต่อจากนั้น" เพราะทำให้ Copy ผิดวัน เข็มที่เหลือไปอยู่การ์ดฟ้า
- ถ้ามีประวัติแล้ว แถว "PCV" ทั่วไปที่ชีตใส่ไว้ในการ์ดเขียวและรายการวัคซีนรอบหน้าจะถูกถอด (โค้ดหาแถวจากชื่อใน `.font-black` ไม่ใช่ข้อความทั้งแถว เพราะข้อความทั้งแถวขึ้นต้นด้วยอีโมจิ เคยพลาดเพราะเรื่องนี้ ดู `tests/ui/harness.html` หัวข้อ genericrow) แล้วใช้แถวตามแผนรายคนแทน (กันซ้ำ และกันบอกให้ฉีดทั้งที่ครบ/ไม่ถึงกำหนด) ถ้ายังไม่เลือกประวัติ แถว PCV ทั่วไปจากชีตยังแสดง

**เข็มที่ตกตอนอายุ ≥ 24 เดือน** (ผู้ใช้สั่ง 3 พ.ย. 2569): ทุกเข็มที่วันที่ (วันนัดหรือวันนี้) ตกตอนอายุ ≥ 24 เดือน มีคำเตือน — **เรื่องวัคซีนของแผนงานใช้ไม่ได้** (2.7) สำหรับทุกเข็มที่ตกอายุ ≥ อายุสูงสุดที่ทะเบียนรับรอง (ตอนนี้ 24 เดือน รวมเข็ม 2 ของผู้เริ่ม 19–23 เดือน) ส่วนข้อความทั่วไป "เข็มนี้ตกตอนอายุ ≥ 24 เดือน — ปรึกษาแพทย์ก่อนฉีดหรือนัด" ใช้เมื่ออายุตกเกณฑ์ที่ CPG ครอบคลุมแต่ยังไม่ถึงอายุสูงสุดของวัคซีน (เช่นถ้าเปลี่ยนวัคซีนที่รับรองนานกว่า) และไม่เตือนซ้ำถ้ามีคำเตือนอื่นอยู่แล้ว (เกินเพดาน, เลยช่วงรอบ, ล่าช้ามาก) (ตัดสินใจเดิม 3 พ.ย. ยกเว้นเข็ม 2 ของ 19–23 เดือน — ยกเลิกเมื่อ 14 พ.ย. 2569)

**เด็กอายุ ≥ 24 เดือน:** CPG แถว ≥ 24 เดือนให้ "พิจารณาตามชนิดวัคซีน" ถ้ายังเลือกประวัติ 1/2 เข็ม ระบบคำนวณแผนให้ตามอายุที่เริ่ม แต่ขึ้น **แถบแดงเด่นที่ด้านบนการ์ด PCV เสมอ** ("ปรึกษาแพทย์ก่อนฉีดหรือนัด PCV") แม้ไม่เหลือการ์ดฟ้า และข้อความ "อายุ 24 เดือนขึ้นไป..." (กรณีไม่เลือกประวัติ/ยังไม่เคยฉีด) เป็นสีแดงด้วย

**การ์ดระยะห่าง:** ใต้แต่ละเข็มที่มีวันที่ของเข็มก่อนหน้า แสดง "ห่างจากเข็ม n−1 = X สัปดาห์" เป็นการ์ดตัวเลขแยก (ข้อความหมายเหตุสีเหลืองไม่ซ้ำตัวเลข)

### 3.2 แท็บ "ค้นหาวันฉีด / ล่าช้า" (สำหรับผู้ปกครอง)

เลือกรอบอายุ แล้วแสดงวัคซีนของรอบและวันเปิดให้บริการถัดไป
- ตัวเลือกพิเศษท้ายรายการ **"PCV เข็มเดี่ยว · ทุกวันพุธ ช่วงเช้า"** → ข้อมูล PCV + วันพุธถัดไปที่เปิด
- การ์ดรอบ 6 ด./9 ด./1 ปี/1 ปี 6 ด. มีหมายเหตุ "เด็กที่เริ่ม PCV ช้า อาจรับ PCV พร้อมรอบนี้ หรือเลือก 'PCV เข็มเดี่ยว'…" (ข้อความแบบทั่วไป เพราะแท็บนี้ไม่รู้ประวัติเด็ก)
- รอบ 2 ด./4 ด./1 ปี แสดง `PCV` (ไม่มีเลขเข็ม) ตามชีต

### 3.3 แท็บ "แผนการฉีดวัคซีน"

การ์ดทุกรอบจากชีต + การ์ด PCV ท้ายตาราง (รอบปกติ, เข็มเดี่ยว ทุกวันพุธ ช่วงเช้า, ระยะห่าง, ตารางตามอายุที่เริ่มเข็มแรกแบบพับเก็บ) ตารางในการ์ดนี้ **พิมพ์ไว้ในโค้ด** (`buildPcvPlanCard`) ไม่ได้สร้างจาก `RULES` ถ้าแก้กฎต้องแก้ตารางนี้ด้วย

### 3.4 เลขเวอร์ชัน

ป้ายบนหัวเว็บ "✨ เวอร์ชัน NN · วันที่ เวลา" (เฉพาะเลขกับวัน-เวลา deploy ไม่มีคำอธิบาย) ต้องเพิ่มเลขทุกครั้งที่ commit+push แก้ `index.html` และต้องเพิ่มรายการของเวอร์ชันนั้น (หัวข้อ + รายละเอียดการแก้) ที่บนสุดของ `server/changelog.json` ซึ่งแสดงในหน้าแอดมินแท็บ "ประวัติเวอร์ชัน" (เทสต์เซิร์ฟเวอร์จะล้มถ้าเลขบนป้ายไม่ตรงกับรายการบนสุด) เพราะ GitHub Pages อัปเดตช้า ใช้เปรียบเทียบว่าเว็บจริงเป็นเวอร์ชันที่เพิ่ง push หรือยัง (กด Ctrl+F5) การซิงก์ชีตอัตโนมัติไม่เปลี่ยนเลขนี้ (เว็บจริงบน server ตรวจเวอร์ชันได้จากป้ายนี้หลัง deploy)

### 3.5 ใช้ offline ได้ และ CSS ที่ฝังในไฟล์

`index.html` **ไม่โหลดอะไรจากอินเทอร์เน็ต** (ไม่มี CDN, Google Fonts, Google Sheets) CSS ของ Tailwind และฟอนต์ Sarabun ถูกสร้างล่วงหน้าแล้วฝังในไฟล์ (ระหว่างคอมเมนต์ `offline-assets:begin`/`end` อย่าแก้ด้วยมือ) เหตุผลที่ฝังไฟล์เดียว: สคริปต์ deploy ของ IT คัดลอกเข้าเว็บเฉพาะ `index.html`, `pcv-rules.js`, `admin.html` **เพิ่ม/เปลี่ยนคลาส Tailwind แล้วต้องรัน `node tools/offline-build/build.js`** (ติดตั้งครั้งแรกด้วย `npm install` ในโฟลเดอร์นั้น) ไม่งั้นคลาสใหม่ไม่มีสไตล์ `tests/offline.test.js` ล้มทันทีถ้าลืมหรือมีลิงก์ภายนอกโผล่กลับมา ข้อมูลโหลดจาก `./data/*.csv` เท่านั้น ถ้าไม่ได้ใช้ข้อมูลที่เก็บใน localStorage

### 3.6 ข้อมูลคลินิกและทางลัด

ชื่อระบบ/ชื่อ รพ./ชื่อย่อคลินิก มาจาก `/data/settings.json` (ตั้งในหน้า admin แท็บ "ข้อมูลคลินิก") ถ้าไม่มีไฟล์ (เช่น GitHub Pages) ใช้ข้อความที่ฝังไว้ ปุ่ม "⚙️ ตั้งค่า" ที่หัวเว็บแสดงเฉพาะเมื่อมีไฟล์นี้ (= เปิดจากเว็บที่มี server ตั้งค่า) ส่วนวันทำการยังเป็นวันพุธฝังในโค้ด (ยังไม่ตั้งค่าได้)

## 5. ข้อสมมุติและจุดที่ยังไม่แน่ใจ

- ระยะห่าง booster 8 สัปดาห์สำหรับผู้เริ่ม 2–6 เดือน ไม่มีแหล่งอ้างอิงตรง (ผู้ใช้ตัดสินใจใช้) ถ้าพบแหล่งที่ต่างออกไป แก้ `d3MinGapDays` ใน `RULES`
- เข็มที่ "พร้อมรอบ" ระบบหาวันเปิดของรอบนั้นเอง ถ้าเด็กมาไม่ตรงวันเปิดของรอบที่ผูก ระบบแสดงตามวันที่ที่มา (เหมือนวัคซีนอื่น) ไม่เตือนเพิ่ม
- วันนัดที่ตกปีที่ข้อมูลวันหยุดยังไม่ครบ ใช้ได้เฉพาะเมื่อคนอ่านป้ายเตือน (พ.ศ. 2570 ณ ปัจจุบัน)
- ตัวเลข "ห่างจากเข็มก่อน" ในหน้าจอคำนวณจากวันที่ของเข็มก่อนหน้าเท่านั้น ถ้าเข็มก่อนหน้าไม่ทราบวันที่จะไม่แสดง
- ตารางสรุปในการ์ด PCV แท็บแผนการฉีด (3.3) ซ้ำกับ `RULES` ต้องแก้สองที่
- ระยะห่างขั้นต่ำของสูตร 3p+1 (ชุดเบื้องต้น ≥ 4 สัปดาห์, กระตุ้นห่างเข็ม 3 ≥ 8 สัปดาห์) ผู้พัฒนาตั้งเอง ไม่มีใน CPG รอผู้เชี่ยวชาญยืนยัน
- ยังไม่ได้ตรวจบนมือถือเครื่องจริง (ตรวจแล้วที่ความกว้าง 390px จำลอง และไม่พบอะไรล้นจอ)
- สถานะการตรวจโดยผู้เชี่ยวชาญของกรณีตัวอย่าง 45 กรณี (`tests/golden/`) ยังเป็น "ยังไม่ตรวจ" ทั้งหมด ผลที่แสดงคือสิ่งที่ระบบคำนวณ ไม่ใช่ข้อยืนยันทางการแพทย์
