# ระบบธีมของหน้าเว็บนัดวัคซีน (index.html)

ผู้ใช้กดปุ่ม **🎨 ธีม** ที่หัวเว็บเพื่อเลือกหน้าตา ระบบจำค่าไว้ในเครื่องนั้น (localStorage คีย์ `wcc-theme`) ไม่กระทบข้อมูลหรือผลคำนวณ

## ธีมที่มี
| id | ชื่อ | หน้าตา |
|---|---|---|
| `lime` | มะนาว (**ค่าเริ่มต้น**) | พื้นขาวโปร่ง ไฮไลต์เขียวมะนาว การ์ดขอบดำบางขอบล่างหนา ปุ่มดำ (ตามแบบ Figma "Positivus") |
| `classic` | ดั้งเดิม | เขียวน้ำทะเล/ฟ้า แบบเวอร์ชันก่อนหน้า (ไม่มีโค้ดทับ) |

## ส่วนประกอบ (ทั้งหมดอยู่ใน index.html ไฟล์เดียว เพราะสคริปต์ deploy คัดลอกแค่ไม่กี่ไฟล์และหน้าต้องใช้ออฟไลน์ได้)
1. `<script>` สั้น ๆ ใน `<head>` — ตั้ง `data-theme` บน `<html>` ก่อนวาดหน้า (กันสีกะพริบ)
2. `<style id="wcc-themes">` — สไตล์หน้าต่างเลือกธีม + บล็อกของแต่ละธีมในรูป `html[data-theme="id"] ...` ภายใน `@media screen` (ไม่กระทบการพิมพ์)
3. `<div id="themePanel">` — หน้าต่างเลือกธีม (สร้างรายการจาก `THEMES` อัตโนมัติ)
4. `<script id="wcc-theme-js">` — รายการ `THEMES`, `setTheme()`, `openThemePanel()`, `closeThemePanel()`; กด Esc ปิดหน้าต่างได้

## ค่าเริ่มต้น
ธีมแรกในรายการ `THEMES` = ค่าเริ่มต้น (ตอนนี้ `lime`) ใช้กับผู้ที่ยังไม่เคยเลือก หรือเบราว์เซอร์เก็บค่าไม่ได้ หรือค่าที่เก็บไว้ไม่อยู่ในรายการแล้ว ส่วนผู้ที่เคยเลือกธีมไว้จะได้ธีมที่เลือก ถ้าเปลี่ยนธีมเริ่มต้น แก้ทั้ง `THEMES[0]` และตัวแปร `t = 'lime'` ในสคริปต์ใน `<head>`

## เพิ่มธีมใหม่ (3 ขั้น)
1. เพิ่มบล็อก CSS ใน `<style id="wcc-themes">` ที่ขึ้นต้นด้วย `html[data-theme="ชื่อใหม่"]` ทับคลาส Tailwind/คลาสเดิมที่ต้องการเปลี่ยน (ดูธีม `lime` เป็นตัวอย่าง) — สีที่สื่อความหมาย (แดง/เหลืองเตือน) ควรคงไว้
2. เพิ่มรายการใน `THEMES` (`id` ตัวพิมพ์เล็ก/ตัวเลข/ขีดกลาง, `name`, `desc`, `swatch` 4 สีตัวอย่าง)
3. รัน `node tools/offline-build/build.js` (Tailwind สแกนชื่อคลาสในไฟล์ จึงต้องสร้าง CSS ฝังใหม่) แล้วรันเทสต์ `node tests/offline.test.js` และ `node tests/ui/run.js`

## แบนเนอร์หน้าแรก (ธีมมะนาว)
มี `<div class="wcc-hero">` อยู่บนสุดของแท็บ "นัดตามอายุ" และ "ค้นหาวันฉีด/ล่าช้า" — ซ่อนไว้ใน CSS พื้นฐาน (`display:none`) และโชว์เฉพาะธีมที่เปิด เช่น `lime` (ภาพกระบอกฉีดยาเส้นบาง วงโคจรหมุนช้า ๆ) ธีมใหม่จะเปิดหรือออกแบบแบนเนอร์ของตัวเองก็ได้ รองรับ `prefers-reduced-motion`

## ส่วนที่ไม่ผูกกับธีม (เลย์เอาต์ตามขนาดจอ)
ใช้ได้ทุกธีม รายละเอียดอยู่ใน [SYSTEM-RULES.md](SYSTEM-RULES.md) ข้อ 3.7: แถบเมนูล่างจอบนมือถือ (`#wcc-tabcard`), ปุ่ม "i" พับคำอธิบาย (`.wcc-help` / `.wcc-i`), กริดการ์ดผลลัพธ์ (`.wcc-rgrid`) และปฏิทินที่ย้ายไปแถบบน (`#wcc-toprow`) ธีมใหม่ควรทดสอบกับส่วนเหล่านี้ด้วย โดยเฉพาะความเปรียบต่างของตัวหนังสือบนพื้นสีเข้ม

## ข้อควรระวัง
- ชื่อคลาส Tailwind ที่ประกอบด้วยตัวแปร (เช่น `bg-${cColor}-500`) สแกนไม่เจอ ต้องเขียนชื่อเต็มไว้ใน HTML comment `tailwind-safelist` (อยู่เหนือ `#themePanel`) ไม่งั้นไม่มี CSS (เคยทำให้ปุ่ม Copy ฝั่งผลค้นหาล่าช้ามองไม่เห็น)
- สีตัวอักษรที่ธีมทับด้วย `!important` ในกลุ่ม `[class*="text-blue-"]` ฯลฯ อาจทำให้ตัวหนังสือบนพื้นเข้มมองไม่เห็น — ตรวจความเปรียบต่างด้วยตาและสคริปต์เสมอเมื่อเพิ่มธีม
- `index.html` เป็น CRLF — แก้ด้วยเครื่องมือ Edit หรือเขียนแบบ bytes
- ค่าธีมที่เก็บไว้แต่ไม่อยู่ใน `THEMES` แล้ว (เช่นลบธีม) จะกลับไปใช้ `classic`
- ธีมที่ทับด้วย `!important` ต้องระวังกฎกลุ่ม "ฟ้า→เทา" ที่ตั้ง `!important` ไว้ (ถ้าจะให้ชิ้นใดเด่น ต้องใส่ `!important` ด้วย)
- ธีมนี้เป็น "สกิน" ทับของเดิม ยังไม่ได้ปรับโครงหน้าหลัก (เช่น ผลลัพธ์เป็นหน้าเต็มแทนป๊อปอัป) นอกจากแบนเนอร์หน้าแรก
